# ERC-7866: Decentralised User Profiles

**Gravatar for Web3** — A standard for on-chain user profiles with usernames, avatars, and multi-dApp identities.

Like Gravatar, but decentralized and on-chain: claim a soul-bound username, set avatars, and sync your identity across Web3 apps with full control and privacy.

📖 **[Read the full specification on EIP-7866](https://eips.ethereum.org/EIPS/eip-7866)**

## Documentation

- **[Implementation Guide](./IMPLEMENTATION.md)** — Complete guide with code examples and integration patterns
- **[Full Specification](./SPECIFICATION.md)** — Technical details, data structures, and security considerations

## Key Features

- Unique, immutable usernames tied to addresses
- Cross-dApp avatars with customizable visibility
- Multi-chain compatible profiles
- Off-chain efficient metadata storage (IPFS/Arweave)
- On-chain privacy enforcement
